Dials (beta): tune a screen's values live and write the picks back to source. In the app, `dial.color`, `dial.number`, `dial.enum`, `dial.boolean`, `dial.text`, `dial.token` (a theme token picked by path) and `dial.variant` (whole components) from `@avasapp/agent-bridge/dials` return a value you can change while the app runs. `useDials({ theme: { tokens, labels, file } })` in the dev bridge file sets up tokens and their readable names, and the bridge component returns `<DialsOverlay />` to outline the element a dial changes. `agent-bridge dials serve` opens a web panel (localhost by default; `--tailscale` or `--host` to reach it from another machine; the key is in the link and stays the same across restarts, `--new-key` replaces it) with controls grouped by element, an outline on the device while you hover, and before and after crops. Picks are saved in `.agent-bridge/dials.json` and survive a session end or an app reload. The panel's Commit button reaches the agent through `dials wait`; the agent writes the values into source, removes the dial calls, and reports with `dials commit-status`. Other commands: `dials list`, `resume`, `clear`, `check`. `agent-bridge init` now adds `.agent-bridge/` to the app's `.gitignore`. Docs: docs/dials.md; agent workflow: skills/agent-bridge/references/dials.md.
