Two new adapters. `@avasapp/agent-bridge/async-storage` (`asyncStorageTools(AsyncStorage)`) gives `asyncStorage.list` (with `{limit, prefix}` and values cut to 200 characters), `get`, `set`, `delete` and `restore`. `@avasapp/agent-bridge/secure-store` (`secureStoreTools(SecureStore, knownKeys, options)`) gives `secureStore.list` (the keys you pass, with set and length), `get`, `set`, `delete` and `restore`; `get` returns `[redacted, N chars]` unless called with `{full:true}`, and `bridge.pending` never shows its keys or values. Pass the same `options` your app gives SecureStore (such as `keychainService`), as one object or a function of the key; they apply to every call, including restore. Keys with `requireAuthentication` are not read by `list`. Both restore what the agent changed, awaiting each async write, and `bridge.restore` and `bridge.pending` include them. A key the app wrote after the agent did is left alone and returned in `skipped`. The originals are kept in memory, so restore before reloading: `app.reload` now names the pending restores it will lose in a `lost` field. `agent-bridge init` adds both, commented out, when it finds the packages.
